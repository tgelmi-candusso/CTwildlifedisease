# CTwildlifedisease

Repository for code relevant to the analysis of sarcoptic mange occurrence across coyotes detected with camera traps in ten cities in North America.

This code was originally generated by Mason Fidino for Murray et al., 2021 and subsequently adapted to multi-city comparison by Mason Fidino and Tiziana Gelmi-Candusso for Gelmi-Candusso and Murray et al., 2026 (in review). The code here has been generated for replication purposes, it includes a multi-state occupancy model, for which more detailed code is available at https://github.com/mfidino/coyote-mange 

The Omniscape folder, due to storage constraints includes only the parametrization document, "omniscape.ini", the code to run it on Julia and the output config.ini document, it does not include the resistance maps. Please e-mail me if you are interested in the connectivity map of your area for further applications. 

References

Murray, Maureen H., et al. "A multi‐state occupancy model to non‐invasively monitor visible signs of wildlife health with camera traps that accounts for image quality." Journal of Animal Ecology 90.8 (2021): 1973-1984.

Gelmi-Candusso and Murray, et al. "Wildlife disease increases with urban densification, habitat connectivity loss and climate change" (in review)

Metadata

data\data_list.rds = data for the conditional model, called directly for in the fit_conditional_mange_model.R 
data\inits.rds = initiation parameters for the conditional model, called directly for in the fit_conditional_mange_model.R 
Omniscape\omniscape.ini = configuration file used to run Omniscape with Julia
Omniscape\output\config.ini = output code with parameters used in our connectivity assessments
Omniscape\Julia\run_omniscape.txt  = code to run Omniscape in Julia using a higher number of threads.
